# Configurable Hunger

Take control of the hunger mechanic and how it affects you! This mod effectively decouples the "world difficulty" from hunger, turning it into a sort of "hunger difficulty."

## Purpose

This mod is basically a "choose your own difficulty" for all things hunger.

- Want the hunger system enabled in peaceful? **You can do that.**
- Want to take control of how hard you're punished for not eating? **Yep, that's possible too.**
- Do you like Peaceful's buffed regeneration, but want it more balanced? **Also adjustable. Configure it to your liking!**
- Maybe you just want to turn hunger off completely in other difficulties? **Believe it or not, that's also supported!**

## Defaults

I assume the average user will be applying this mod to enable hunger mechanics in peaceful difficulty. Out of the box, the mod comes with the following settings configured:

- Hunger will deplete in Peaceful.
- Starvation is based on Normal difficulty (dropping you down to 1/2 heart).
- Peaceful's unique buffed health regeneration is never active.

But as stated in the purpose section, this is all configurable.
